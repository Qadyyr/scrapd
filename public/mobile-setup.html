Choose your platform to set up one-tap Scribd extraction on mobile.

iOS Shortcuts — Native, no bookmarklet

Install the Scribd Extractor Shortcut

Uses iOS Shortcuts to run JavaScript on any Scribd page. No bookmarklet needed — just tap Share → Shortcuts.

1
Tap the button below to open the Shortcut in the Shortcuts app.
📥 Install Shortcut
2
Tap "Add Shortcut" in the Shortcuts app.
3
To use: Open any Scribd document in Safari → tap Share → tap "Extract Scribd".
4
The Shortcut runs JavaScript on the page, extracts all page images, and opens the downloader app automatically!

💡 How is this different from a bookmarklet?

Bookmarklets require manually creating a bookmark with a javascript: URL — which mobile browsers often strip or block.

iOS Shortcuts are native iOS automation. They run JavaScript on web pages through the Share menu — no bookmarklet, no manual URL editing.

Kiwi Browser extensions run automatically on every Scribd page — zero clicks after installation.
