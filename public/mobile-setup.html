📱 Mobile Setup

Set up one-tap Scribd extraction on your phone.

🍎 iPhone / iPad (iOS Shortcuts)

Use iOS Shortcuts to run JavaScript on Scribd pages via the Share menu. No bookmarklet needed.

1
Open the Shortcuts app on your iPhone. Create a new shortcut.
2
Add action: "Run JavaScript on Web Page"
3
Tap the button below to copy the JavaScript code, then paste it into the shortcut:
4
Add action: "Get Contents of URL". Set URL to , method = POST, headers = Content-Type: application/json, body = "JavaScript Result".
5
Add action: "Open URL". Set URL to + "/" + "?extract_id=" + (Dictionary from step 4 → "extractId")
6
Tap the info icon (ⓘ) → enable "Show in Share Sheet". Name it "Extract Scribd". Save.
To use: Open any Scribd document in Safari → tap Share → tap "Extract Scribd". The shortcut extracts the pages and opens the downloader!

🤖 Android (Kiwi Browser)

Kiwi Browser supports Chrome extensions on Android. Install the extractor extension for one-tap extraction.

1
Install Kiwi Browser from the Play Store.
2
In Kiwi, open kiwi://extensions and enable Developer mode.
3
Tap the button below to download the extension code:
4
Create a folder on your phone with two files: manifest.json and background.js. Copy the content from the downloaded file into each.
5
In Kiwi kiwi://extensions → "Load" → select the folder.
To use: Open any Scribd document in Kiwi → tap the extension icon (puzzle piece) → tap "Scribd Extractor". Done!
